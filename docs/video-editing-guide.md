# 视频配音与导出操作

`LayerTrace-demo.mp4` 已包含中文配音与同步字幕，可以直接提交。以下步骤用于需要替换为本人声音的情况。

## 直接提交

1. 打开 `LayerTrace-demo.mp4`，检查开头、CPU实验、工具故障与恢复结尾的声音及画面。
2. 使用本地 `LayerTrace-demo.mp4` 文件作为提交成片。GitHub 只放源码，视频与配音素材保存在本地；如比赛要求视频链接，由参赛者选择平台上传。
3. 视频时长4分30秒，H.264画面、AAC音轨，1600×900、25fps。页面展示已完成的真实实验记录。

## 用剪映替换为本人配音

1. 新建项目，导入 `LayerTrace-demo.mp4`，放到主轨，保持整段4分30秒。
2. 选中视频，将“音量”设为0；画面和已有中文字幕保留。
3. 打开 `Video-narration.md`（源码中为 `docs/video-narration.md`），按九个时间段录音。先录一段，再播放检查，不需要一次读完整篇。
4. 点击“音频 → 录音”，把播放头放到该段开始后0.5秒；点击录制，照稿朗读该段，然后停止。依次录制九段。
5. 对齐段首：0:00.5、0:12.5、0:40.5、1:15.5、1:40.5、2:35.5、3:15.5、3:50.5、4:10.5。旁白结束后保留操作画面，不压缩证据阅读时间。
6. `LayerTrace-subtitles.srt` 可作时间参考；成片已有烧录字幕，不重复显示第二层字幕。本人语速和字幕偏差明显时，按对应句子调整录音位置或重录该句。
7. 开启适度人声降噪，统一各段音量，避免音量表持续触顶。全片播放一次，检查没有重叠、截断或漏读，最后一句“谢谢”位于视频结束前。
8. 导出MP4，使用H.264、25fps、1080p或保留原分辨率；音频选AAC、48kHz。导出后重新打开导出的文件，核对时长4分30秒、声音与字幕同步。

## 随附文件

- `LayerTrace-demo.mp4`：已完成中文配音与字幕的提交视频。
- `LayerTrace-narration.wav`：独立普通话旁白音轨，48kHz。
- `LayerTrace-subtitles.srt`：同步中文字幕。
- `Video-narration.md`：逐镜头口播和时间码。
- `UI-operation-guide.md`：详细页面操作。
